Simple à installer, chez vous

Un serveur média, sans ligne de commande.

Lancez Bobine sur votre ordinateur, choisissez votre dossier depuis la page de configuration, puis retrouvez le serveur sur votre réseau local.

▤

Une bibliothèque à vous

Bobine rassemble votre médiathèque locale et ses informations dans une interface accessible depuis votre serveur.

⌂

Chez vous, sur votre réseau

Votre ordinateur héberge le serveur. Un appareil connecté au même réseau peut le retrouver pour parcourir et lire la bibliothèque.

▶

Conçu pour votre téléviseur

Associez le client Android TV ou Google TV à Bobine pour parcourir la bibliothèque et lancer une lecture.

Télécharger Bobine

Choisissez le paquet correspondant à votre ordinateur. Le serveur et son lanceur sont inclus ; aucune installation de .NET n’est nécessaire.

⊞Windows

Pour les PC Windows 64 bits. Décompressez le ZIP puis lancez Bobine.exe.

Télécharger pour Windows
MMac · Apple Silicon

Pour les Mac avec puce Apple (séries M). Ouvrez le ZIP puis déplacez Bobine.app dans Applications.

Télécharger pour Mac Apple Silicon
MMac · Intel

Pour les Mac équipés d’un processeur Intel. Ouvrez le ZIP puis déplacez Bobine.app dans Applications.

Télécharger pour Mac Intel

La première configuration requiert un jeton TMDB et une clé API OpenSubtitles. Sur Mac, le paquet n’est pas encore signé ou notarié ; Windows peut afficher un avertissement SmartScreen. Voir les notes de version et les autres fichiers.
